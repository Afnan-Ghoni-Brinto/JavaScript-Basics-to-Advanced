## Requirements
- Modern web browser
- Visual Studio Code or another code editor
- Node.js for terminal examples

## Run JavaScript
For a standalone Node.js example:
```bash
node 01_JavaScript_Basics/01_hello_world.js
```
For DOM, BOM, and browser-storage examples, open the matching `.html` file in a browser. Browser-only APIs such as `document`, `window`, `prompt`, `alert`, and `localStorage` do not run in ordinary Node.js scripts.

ES module examples in `10_ES6_Plus` work with the included `package.json`.

## Learning Advice
Run each example, change values, predict the output, and then test your prediction. Try writing a similar example without copying.
